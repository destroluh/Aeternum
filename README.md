# Aeternum

Aeternum é uma história interativa criada no Twine (Harlowe). O leitor assume o papel de Mnis e avança pela narrativa percorrendo referências de diferentes períodos, movimentos e linguagens da História da Arte, aprendendo a ler obras, contextos e símbolos por meio dos enigmas e escolhas que a trama propõe.

## Como jogar

Você já está com o jogo aberto no navegador. A partir daqui:

1. Aguarde alguns segundos até a tela inicial carregar por completo.
2. Clique em **"Começar a jornada"**.
3. Leia o texto e clique nas opções para avançar na história.

Pronto. Não é preciso criar conta, fazer login, baixar arquivo ou instalar programa.

### Controles

- **Avançar na história:** clique nas opções de escolha que aparecem ao final de cada trecho.
- **Continuar de onde parou:** o jogo salva o progresso automaticamente. Ao reabrir, clique em **"Continuar"** na tela inicial.
- **Tela cheia:** pressione **F11** (computador) para uma leitura mais confortável.

### Se algo não funcionar

- Verifique se há conexão com a internet.
- Tente outro navegador (Chrome, Edge, Firefox ou Safari).
- Se estiver no celular, gire a tela para a horizontal — a leitura fica melhor.
- Se a página parecer travada, recarregue com **F5** (computador) ou puxando a tela para baixo (celular).

## Alternativa: jogar pelo arquivo

Caso prefira abrir o jogo diretamente no computador, sem depender do link:

1. Acesse a página de versões: https://github.com/destroluh/Aeternum/releases/tag/v1.0
2. Em **Assets**, clique em **Source code (zip)**.
3. Extraia o arquivo ZIP baixado (botão direito → Extrair tudo).
4. Dê dois cliques em **Aeternum.html**.
5. O jogo abrirá no navegador padrão.

| Ferramenta | Uso no projeto |
|---|---|
| **Twine 2** | Motor de criação da narrativa interativa |

| **HTML/CSS** | Personalização visual da interface |
| **GitHub** | Versionamento e hospedagem do projeto |
